# ПДД Тренажёр

Приложение для подготовки к теоретическому экзамену ПДД. React + TypeScript + Vite + Capacitor 6, Zustand, Tailwind, тёмная премиальная тема.

## Стек и архитектура

```
package.json, vite.config.ts, tsconfig*.json, tailwind.config.js, postcss.config.js
capacitor.config.ts, index.html
src/
├── main.tsx, App.tsx        — точка входа, навигация, кнопка "назад" на Android
├── types.ts                 — Category, Screen, ActiveSession и т.д.
├── data/
│   ├── pddQuestions.ts       — типизированный доступ к вопросам
│   ├── questionsAB.json      — 800 вопросов, категория A,B
│   ├── questionsCD.json      — 800 вопросов, категория C,D
│   └── topicsAB.json / topicsCD.json
├── utils/
│   ├── examEngine.ts         — чистая логика билета (блоки, доп.вопросы, провал)
│   └── stats.ts              — статистика по темам, список активных ошибок
├── store/useAppStore.ts     — Zustand + persist (localStorage): категория, история, результаты
├── screens/                  — 6 экранов: Home, Tickets, Question, Results, ErrorReview, Statistics
└── components/                — GaugeProgress (гейдж-индикатор, фирменный элемент), AnswerOption,
                                  QuestionImage, ScreenHeader, TileButton, TicketCard, CategoryToggle, TopicBar
public/pdd-images/ab, public/pdd-images/cd  — 541 + 539 картинок к вопросам
```

Проект **собран и проверен**: `npm install`, `tsc -b` и `vite build` прошли без единой ошибки.

## Логика экзамена (проверено по актуальным правилам ГИБДД на 2026 год)

- Билет — 20 вопросов, разбитых на 4 тематических блока по 5 (позиции 1-5, 6-10, 11-15, 16-20).
- Допускается не более 2 ошибок, и обязательно в **разных** блоках. Вторая ошибка в том же блоке — незачёт.
- За каждую ошибку — 5 дополнительных вопросов по теме этой ошибки и +5 минут времени.
- Любая ошибка в дополнительном вопросе — незачёт немедленно.
- В режиме экзамена правильность ответа **не показывается сразу** (как на настоящем экзамене) — только в самом конце, на экране результата. В режиме обучения — разбор сразу после каждого ответа.

Вся эта механика — в `src/utils/examEngine.ts`, отдельно от UI, легко покрыть тестами при желании.

## Запуск

```bash
npm install
npm run dev              # http://localhost:5173
```

## Сборка и Android (тот же пайплайн, что и в голосовом блокноте)

```bash
npm run build
npx cap add android      # один раз, если ещё не добавлено
npx cap sync android
```
Дальше — тот же `gradlew assembleRelease` + `apksigner` через GitHub Actions с уже знакомыми секретами (KEYSTORE_BASE64, KEY_ALIAS, KEYSTORE_PASSWORD, KEY_PASSWORD).

## Иконки

Встроены по-настоящему — все плотности (mdpi…xxxhdpi), adaptive icon (foreground + фон с тем же янтарным бликом, что и в приложении, не плоский цвет) и splash под все 11 размеров шаблона Capacitor. Круг-гейдж + галочка — сознательно тот же визуальный язык, что и GaugeProgress в самом приложении. Исходники и скрипт генерации — в `resources/` и `scripts/gen_icons.py` / `scripts/embed_android_icons.py`, если захочешь другой вариант.

`@capacitor/assets` в этой песочнице не встал (тянет нативный `sharp`, а его бинарник качается с GitHub releases — туда закрыт доступ), поэтому разложил файлы вручную по тем же путям и размерам, что использует сам шаблон Capacitor — надёжнее ручной раскладки в прошлый раз, потому что здесь размеры сверены с реальными файлами шаблона, а не подобраны на глаз.

## Реклама (Яндекс РСЯ)

Код уже в `index.html` + `src/utils/ads.ts` — тот же JS-метод, что и в голосовом блокноте. Баннер скрывается на экране вопроса (не перекрывает кнопку "Далее"), интерстишиал показывается на результате после экзамена (не после обычного обучения — иначе будет слишком навязчиво).

**Единственное, что нужно перед запуском** — ID блоков в `index.html` (`window.PDD_AD_BLOCKS`) сейчас заглушки `R-M-000000-1/2`. Блоки голосового блокнота сюда переносить нельзя — они привязаны к другому пакету (`ru.voicenote.app`). Нужно зарегистрировать `ru.pddtrainer.app` в partner.yandex.ru (тот же процесс, что уже проходили) и подставить реальные ID.
